# 工作台界面维护规则

以 Git 已提交界面为准，保留现有配色、字体、圆角及密度，不进行整站重设计。

## 运行时样式
workbench.html 的 :root 与内联样式是两个工作台共用的样式来源；项目表使用 index.html。pages.mjs 由 build-pages.mjs 生成，禁止直接修改。

## 布局与交互
手机端顶部导航换行展示，不依赖横向滚动发现入口。日历和安排在桌面并排，手机纵向排列；安排卡片按内容高度显示。手机按钮和表单操作至少 44px 高。原生表单、共享 edit/change、云端 patch 保存沿用现有实现。

## 验证
node --test；桌面与 390px 手机预览。页面生成时统一 LF，跨系统一致性测试仅忽略 CRLF 与 LF 的差异。

## 动画
按钮反馈 140ms，菜单和弹窗入场 160–180ms，以 opacity 和 transform 为主；不对数据刷新后的整页重复播放动画。日历提醒采用 6 秒轻量位移，后台及悬停暂停。减少动态效果设置禁用所有非必要动画与过渡。
