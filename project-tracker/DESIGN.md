# 工作台界面维护规则

以 Git 已提交业务代码为基础。用户最新目标是可面向公众展示的正式工作台产品官网，明确参考 Apple 官网的视觉质量；该目标取代此前“不进行整站重设计”的限制。已废弃的 CardNav 和深紫改版仍不采用。

## 运行时样式
workbench.html 的 :root 与内联样式是两个工作台共用的样式来源；项目表使用 index.html。pages.mjs 由 build-pages.mjs 生成，禁止直接修改。

## 布局与交互
手机端顶部导航换行展示，不依赖横向滚动发现入口。日历和安排在桌面并排，手机纵向排列；安排卡片按内容高度显示。手机按钮和表单操作至少 44px 高。原生表单、共享 edit/change、云端 patch 保存沿用现有实现。

## 验证
node --test；桌面与 390px 手机预览。页面生成时统一 LF，跨系统一致性测试仅忽略 CRLF 与 LF 的差异。

## 动画
按钮反馈 140ms，菜单和弹窗入场 160–180ms，以 opacity 和 transform 为主；不对数据刷新后的整页重复播放动画。日历提醒采用 6 秒轻量位移，后台及悬停暂停。减少动态效果设置禁用所有非必要动画与过渡。

## 正式产品官网
品牌暂沿用“我的工作台”，不虚构企业资质、使用人数、客户评价或注册服务。公开 `/` 产品介绍使用大标题、真实功能说明和专门编写的交互示例；示例不访问 API，不包含真实用户记录。工作空间采用冷白和蓝色，生活空间使用浅暖色与深绿，强调独立空间和日常推进。

首页、图标无需登录；工作台页面和全部数据接口继续鉴权。原生移动导航、键盘焦点、Escape 关闭、减少动态效果、无 JavaScript 时可见内容为必要基线。上线前验证公开页面与受保护路由边界、桌面/手机布局、示例切换、入口链接及生产响应。

## 产品内页
`workspace-design.css` 为工作台和项目表的统一产品视觉来源，由 build-pages.mjs 嵌入两份 HTML。工作空间采用冷白与蓝色，私人空间采用浅暖色与深绿；两者均保留日历，私人首页同时显示每日清单与英语学习。表单、菜单、提醒、娱乐封面与项目表沿用既有操作和保存逻辑，仅扩展共享视觉规则。登录页面保留既有 CSRF、限流、自动填充与安全 Cookie 规则。

相似功能通过统一主入口和内容标签整合：计划包含日历与待办，私人娱乐包含记录与即将发售；保留原数据模型和编辑流程。公开官网压缩章节留白，交互示例支持空间切换与完成计数。当前仅保留本地预览，未经再次授权不发布。

工作台不展示游戏或发售入口；游戏娱乐与发售信息仅由私人工作台的娱乐入口访问。

游戏封面统一采用 Steam library_600x900 竖版资源，查找不再回退到 PlayStation。旧的非 Steam 游戏封面在展示时重新匹配；电影等其他媒体保留各自来源。

当前配色决定：工作和私人工作台统一采用冷白与蓝色共享色板，取消私人暖色深绿覆盖；两边功能、数据范围和布局保持独立。

页面不展示数据来源名称、来源链接和媒体筛选说明；来源元数据保留在后台用于匹配与筛选。游戏详情入口、日期、数量和加载异常状态继续展示。

## 2026-10-14 已批准内页设计
用户批准 Linear 的紧凑布局与 shadcn 浅色视觉组合并上线。工作空间采用 208px 左侧导航、冷白底色、细边框和蓝色操作色；首页显示真实问题统计。项目问题采用按项目分组的紧凑列表，详情通过右侧原生 dialog 编辑。modern-workspace.css 限定工作空间与项目表，私人空间数据保持独立。沿用云端按记录 patch、冲突处理与鉴权；预览演示数据不发布。

项目问题分组以项目名称为依据，按项目编号自然排序；进行中、暂停与已完成问题仍保留各自行状态，同一项目不因状态不同拆成多个分组。筛选后的分组数量只计算当前可见问题。

同一项目名称在所属项目列使用 rowspan 合并，不再额外重复项目标题。全站现有固定字号统一增加2px，保持既有布局、行高比例和工作/私人空间视觉差异；公共首页及登录页面同步增大。

所属项目列置于第一列并跨行合并。添加入口区分新建项目与添加问题；空项目独立保存到 projects 集合，不生成虚假问题。全部问题视图显示0问题项目并提供添加问题入口，问题状态、超期和日期筛选不显示空项目；搜索项目名和优先级筛选继续生效。

项目问题表仅保留“全部问题”，移除逾期/今日快捷标签和状态、超期、优先级筛选框。搜索默认以44px图标按钮显示，点击展开输入，Escape清空并收起。所属项目合并单元格跟随项目优先级着色：紧急浅红、高浅橙、中浅蓝、低浅灰；优先级文字继续保留，空项目使用相同规则。

报销功能从工作台导航、列表和编辑表单移除，存量费用仅保留在数据兼容层。项目问题表新增独立备注列，空备注显示“添加备注”，已有备注显示完整文本；点击复用问题详情的备注字段并聚焦，沿用原有冲突检查和云端保存。

资料页仅展示项目核心信息表，五列为项目、供货范围、运输方式、托盘尺寸、设备负载。按项目信息表已核实数据展示快照，缺失及冲突保留“待确认”，贸易条件不得直接等同运输方式，设备载荷按设备类型区分。业务内容存于登录保护的独立数据表，不内嵌页面或提交代码仓库；桌面完整表格，窄屏由表格容器横向滚动，保留加载、失败重试和空数据状态。
