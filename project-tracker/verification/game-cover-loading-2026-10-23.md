# 游戏封面补齐与加载优化

2026-10-23。用户要求补齐封面并处理每次加载慢。

## 已核实与修改

- 通过只读 D1 查询核对17条游戏记录，其中6条 coverUrl 为空；通过现有登录会话和记录编辑表单逐项补齐。前后数据比较确认仅这6条记录的 coverUrl 变化，名称、平台、状态、日期、评分、进度、历史及其他记录均保留。没有直接SQL更新生产数据。原始记录与差异留在私有临时材料，不提交数据库快照或真实记录ID。
- 按 Steam App ID 的官方资料核对5个作品；PSP作品使用原版包装图，未替换成重制版。17个游戏图片链接经新代理的相同来源校验、取图和字节限制逻辑验证，全部HTTP200且有有效图片类型和非空内容。这是本机到图源的连通性验证，不代表所有用户地区的延迟。
- `media-image.mjs`及`worker.mjs`：增加登录后访问的同站图片接口。固定8个图源主机、HTTPS、位图扩展名及响应类型，禁止凭据/非标准端口/重定向，不转发用户Cookie，单图最大2.5MB、8秒超时。Cloudflare Cache API缓存公开图片7天，客户端私有缓存7天；Steam资源版本参数t保留，移除无关追踪参数。Fastly资源地址映射至同一官方资源的Akamai节点。缓存读写不可用仍可读取有效图源。失败不缓存。
- `media-library.js`、`media-cover-picker.js`：作品封面墙、列表、候选及编辑预览统一使用受支持来源的同站图片；其他自定义来源保留。首屏6张eager、其余lazy，异步解码、预留宽高；不改2:3槽位或游戏contain比例。失败隐藏损坏图片并保留作品名称。缺封面且有来源ID的详情查询从串行改为最多4路并行，同请求去重，失败允许重试，手动封面不自动替换。
- `media-sources.mjs`：成功的按ID详情允许浏览器私有缓存1小时；搜索与错误仍no-store，显式搜索/刷新no-cache。
- `开发规则.md`在原封面规则处维护约定；资源由build:pages重建。

## 解锁后正式站复核与补修

首次正式站逐屏复核发现15张已显示，2张Wikimedia封面在生产服务器转取失败。本机17个图源连通不等于生产取图成功，前次验收范围不足。Safari直接打开PSP原版图片正常，因此Wikimedia恢复直接读取并使用原站浏览器缓存，其余支持来源仍使用同站缓存；封面墙、列表、候选及预览增加一次原图回退，避免代理故障遮蔽可用原图。新增单次回退测试；本次不改生产业务字段。最终正式浏览器检查及发布版本在发布回执中补记。
