桌面实测工作空间7页、私人空间15页、登录页、独立项目页，共24个页面状态。22个空间页面逐一检查390px布局；工作概览、项目、健身、词汇库另查320px。检查笔记、待办、共享日期、娱乐记录、衣橱、日历新增、日历日期、项目抽屉及个人中心。所有数据为隔离预览示例，不连接生产业务数据，不提交表单。

## 初次检查结论（修复前）

主题主色及正文14px基本一致，普通卡片底色与20px圆角大体一致；按钮、日期与卡片阴影仍由多套实现控制。只改色板不能统一全部控件。

### 1. P1 · 项目编辑抽屉顶部越界（已修复，第二轮复查通过）

项目问题 → 点击问题标题。等待动画结束后，内嵌视口952×600，弹层边界left232/top-300/width480/height600；标题、关闭及上部字段被裁。workspace.css:2907的独立translate:-50% -50%被ui-project-drawer继承；变体workspace.css:2967只设transform:none，不能清除translate。应在现有变体处修正定位，并复查内嵌/独立、桌面/手机、表单内部滚动与保存取消可达。证据dialog-project-stable.jpg。不可仅缩小弹窗或隐藏越界。

### 2. P2 · 同级按钮外观仍分裂（已修复，第二轮复查通过）

React待办/训练的outline辅助操作默认透明底；原生页面取消/刷新默认近白底。原生今日任务与编辑表单按钮圆角9px，React按钮10px，日历编辑底部按钮6px，登录按钮25px。React outline默认transparent定义在vendor/shadcn-glass-ui/button-glass.tsx，原生按钮由workspace.css及data-ui-control适配。应先在应用共享Button中明确primary/secondary/outline/ghost业务用途，再把原生DOM适配到相同变体；不把导航项、表格标题、危险操作及普通按钮全部涂成同一色。上游保留文件不应作为各页修补位置。

顶部收起与通知按钮本次已确认相同：44×44px、16px圆角、相同底色/描边/阴影，是浮岛图标按钮的明确变体。

### 3. P2 · 日历控件尺寸及层次未统一（已修复，第二轮复查通过）

首页/生活日历工具栏前后按钮34px，今天/月/导出/新建36px；新增日程底部取消和创建32px、圆角6px；关闭约24px。其他编辑表单操作按钮44px。日历备注框约64px，普通表单多行输入140px。日历日期和时间按钮仍沿用上游尺寸。应通过日历适配层接入共享控件规格，并保证手机换行及44px点击区域；时间格/日程条是信息密度例外，不机械扩大成普通按钮。

### 4. P2 · 两套日期选择器周起始日及呈现不同（已修复，第二轮复查通过）

主日历及日历内日期弹层已从周日开始；待办截止日期、娱乐开始完成日期、项目计划日期等共享DateChooser仍从周一开始。components/date-model.mjs:dateGrid使用(first.getDay()+6)%7，workspace-date.tsx列头也固定周一。应统一周起始配置，并一起改列头、日期网格和键盘Home/End，不能只改文字。

### 5. P2 · 词汇导入和文件选择遗漏共用样式（已修复，第二轮复查通过）

词汇库“导入词汇”是label.btn，实测42px高/0px圆角/16px字体，邻接操作44px/10px/14px。workspace-primitives.tsx的适配选择器覆盖button.btn和a.btn，遗漏label.btn。隐藏文件输入与label还须验证键盘可达。衣橱照片与日历图片附件保留系统文件选择按钮，视觉与普通控件不同。应复用共用Upload触发器及真实input，保留文件选择、校验和焦点行为。

### 6. P2 · 同级卡片阴影不同（已修复，第二轮复查通过）

笔记/需求/首页原生card使用0 4px 16px的淡蓝灰阴影；英语练习、训练档案及个人信息React卡片采用Tailwind shadow-sm的1/2px黑色双阴影。卡片底色及20px圆角基本一致，差异在shadow变量作用域。应将相同层级卡片映射到统一card组件token，浮层可保留不同层级。

### 7. P2 · 日历中文不完整（已修复，第二轮复查通过）

新建日程颜色仍显示Blue；日期弹层上/下月辅助名称为Previous month/Next month；共享DateChooser则是上个月/下个月。应补齐上游translations与日期弹层locale/aria，保留用户自选颜色的数据值。

### 8. P3 · 部分说明与页面用途不符（已修复，第二轮复查通过）

个人中心只有个人信息与退出登录，但说明是“填写内容后保存，或取消返回当前页面。”原因是原生弹层适配器看到了退出登录form，即推断为编辑表单。应为个人中心提供明确说明，不能用是否存在form推断业务语义。

### 9. 日历新增白屏（本次检查已修复）

点击新建曾报ReferenceError: React is not defined并清空日历，源于calendar-ui/src/attachments.jsx使用JSX但构建沿用classic transform且无React绑定。已在calendar-ui/build.mjs显式使用jsx:automatic，重新生成资源并浏览器确认“新建日程”表单与附件入口正常显示，取消可返回。没有改保存协议或上传逻辑。

## 不应当误报的不一致

- 工作概览是日历、私人首页是我的一天；工作与私人待办默认表格/看板有现行规范依据。
- 主页大标题34px、内页28px、面板18px属于层级差异，不要求全部同字号。
- 主操作、次操作、危险操作、导航和文字链接应有明确不同变体。
- 工作待办宽表在内部横向滚动，单元格在视口外不等于整个页面溢出。
- 隐藏的原生select/date用于表单值兼容，不按1px隐藏节点报告控件尺寸失败。
