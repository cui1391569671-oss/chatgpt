## 原因与修复

- 日历视图交互后，旧适配器再次给 RubberSegment 单选按钮添加普通按钮边框和内边距，导致按钮文字与滑块文字错位。适配器在原归属边界排除共享组件，组件明确声明所有者。
- 顶部搜索已改成图标按钮，但旧搜索文字和快捷键节点仍存在；删除旧节点及过时宽度、文字样式，保留快捷键、名称和提示。
- 768px 工作待办的搜索框被压缩，输入框与状态筛选相撞；在共享搜索容器修正最小宽度与换行，删除局部旧宽度。
- 娱乐类别、记录页面、衣橱切换直接挂载共享分段组件，删除废弃应用按钮及事件分支。日历第三方受控节点仅作为必要 API 桥保留并隔离可见性和焦点。
- 复查发现年度分类和日期面板中的下拉 Esc 会误关父层。在共享 Dialog/Sheet 统一处理属于当前下拉的键盘事件，覆盖弹层内焦点及刚展开仍停留触发器的情况，删除原生适配器重复关闭分支。
- 在唯一开发规范《开发规则.md》维护旧控件退役、组件所有权及交互后验收要求；未新增另一份开发规范。
