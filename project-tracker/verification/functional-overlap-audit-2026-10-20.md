# 页面功能重复检查（2026-10-20）

## 范围与结论

基于 main 提交 `3260f80`，核对页面入口、业务表单与持久化数据来源。浏览器使用本地 8798 隔离数据，打开工作 8 个视图、私人 12 个视图和独立项目页；另查看娱乐发售、四季穿搭、个人中心及相关编辑表单。未修改业务代码、未保存测试记录、未操作生产数据。

发现一组较明确的业务重叠（游戏待办与娱乐记录）、三组需要明确边界的相似功能、四类可精简入口，以及旧实现残留。多入口或共用数据不等于重复存储；本次未读取生产业务记录，不能据此判断用户实际有多少重复记录。

## 功能重叠与建议

| 部分 | 当前证据 | 建议 |
|---|---|---|
| 私人游戏待办 / 娱乐记录 | 待办表单可选“想玩的游戏”，保存到 tasks；娱乐记录同时支持游戏的想玩、进行中、已完成等状态，保存到 completedGames。名称、平台及状态需分别维护，没有自动关联。 | 游戏作品与游玩状态以娱乐记录为主；如需截止提醒，让待办关联作品。涉及已有游戏待办时先做迁移预览，不直接删除。 |
| 每日清单 / 重复日程 | dailyRoutines 按 completedOn 记录当天勾选；events 支持每天重复及单次完成状态，两者独立。 | 明确每日清单用于不固定时间的习惯，重复日程用于有时间段的安排；暂不直接合并。 |
| 年度计划 / 生活计划日历 | annualPlans 独立保存起止日期、分类和进度；日历读取 events、tasks，不读取年度计划。相同事项放入两处需维护两次。 | 保留年度目标与每日排期的区分；需要联动时从年度计划投影里程碑或建立关联，不再复制整条记录。 |
| 项目问题 / 工作待办 | 项目表记录问题、原因、计划日期和状态；tasks 保存通用待办。两类均展示在日历、今日任务和提醒，彼此不会自动去重或互相完成。 | 项目问题在项目页维护，通用工作在待办页维护；需要执行子任务时增加明确关联。不能仅按标题相同自动合并。 |

## 可精简的重复入口

1. **新建项目有三处流程**：添加选择中的“新建项目”、添加问题的项目下拉“＋新建项目”、项目管理中的“添加项目”。入口可保留，但新建、校验与保存流程应复用同一实现。证据：index.html 的 showProjectCreate、confirmNewProject、manageProjects。
2. **单词练习有两个返回词库按钮**：顶部“词汇库 →”与底部“返回词库”都调用 leave，再由 word-practice-adapter.js 跳转同一词库。建议保留顶部入口；进行中的“结束练习”承担中断语义，需保留确认行为。
3. **待办标题与编辑按钮打开同一面板**：tasks-ui/src/main.tsx 同时通过标题和“编辑”按钮 setEditor(row.original)。属于操作冗余，不会创建两条数据；可采用标题进入详情、操作菜单负责编辑，或仅保留一种明确的编辑方式。
4. **切换空间菜单中的“工作台首页”与工作空间目标重合**：workspace-shell.tsx 链接 `/`，worker.mjs 将其重定向 `/work`。公开首页已停用，建议删去该冗余菜单项或改为明确命名，避免私人空间误认为返回私人首页。个人中心内的空间切换是同一目的的次要入口，可按使用习惯保留。

## 应保留的共享视图与独立功能

- 工作概览日历、今日任务、消息提醒读取原始任务/项目/日程，没有额外建立同名业务记录。日历用于排期；今日任务只列当天；提醒列未完成的逾期、今天与明天到期项，范围不同。
- 顶栏“资料/笔记”等快捷入口与侧栏打开同一视图，是导航捷径。
- 工作与私人空间的待办、需求和笔记具有相同操作，但数据隔离，不能混并。账号个人信息则按设计共用同一资料库；浏览器隔离环境未模拟加密资料库，因此未核验解锁后的资料内容。
- 需求登记保存功能改进及处理状态；笔记保存自由文字；应保留两者。需求当前不自动建立待办或日程。
- 词汇库管理词条，单词练习记录学习结果，首页每日词汇从同一词库抽取，不是三套词库。
- 娱乐记录维护个人作品状态；即将发售和今年已发售来自外部榜单，是发现作品的入口，不应混成个人记录。
- 衣橱保存衣服，四季穿搭保存衣服组合，不是重复衣物。
- 居家健身记录训练安排和实际组数；每日清单仅勾选习惯，数据粒度不同。
- 项目资料展示项目核心信息，项目问题记录处理过程，职责不同。隔离环境没有生产资料/外部账号，未核验生产导入内容及 Google 登录。
- 工作台内嵌项目页和独立 `/projects` 使用同一项目实现与数据，不是两份项目表。

## 旧实现残留（区别于用户可见重复）

- workbench.html 在 `edit()` 与 `renderResults()` 先转交 React 待办组件并返回，后面仍保留旧待办表单/列表分支。这些分支应评估移除，不能把已隐藏旧实现当作另一个可见页面。
- Drive 常用链接、预览函数和表单仍保留；当前资料页已经改为项目核心信息，未提供这些常用链接入口。清理代码前保留既有 driveLinks 数据兼容。
- homePie、todaySchedule、nextTasksCard 等旧首页函数保留，但当前 productHome 不调用它们。
- 娱乐删除处理器连续赋值两次同一 onclick；后一赋值覆盖前一赋值，不会因该重复而删除两次。
- worker.mjs 有三处 favicon GET 分支，最前分支已返回，后两处不可达。
- 构建生成的 HTML 样式块、pages.mjs、tasks-assets.mjs 等重复内容属于生成产物，不应以“去重”为由直接删除或手工修改。
