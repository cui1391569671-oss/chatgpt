- workbench.html：/work、/personal 共用；index.html：/projects，可同源嵌入；/ 跳转 /work。landing.html 留作历史源码，不是公开入口。
- tasks-ui/src：待办、年度计划、英语练习、健身、个人资料及共享组件；calendar-ui/src：日历、重复规则及附件。
- *-adapter.js 与 workbench-shell.js 连接原生状态和 React 生命周期。
- build-pages.mjs 生成 pages.mjs、主题及 HTML 嵌入块；tasks-ui/build.mjs 与 calendar-ui/build.mjs 生成组件资源。生成重复内容不得按死代码删除。
