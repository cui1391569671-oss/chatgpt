# 环境配置清单

配置值不在本文件记录；真实Secret不进入Git、URL或浏览器日志。本批未读取生产Secret、修改云端绑定或安装Apps Script触发器。

| 名称 | 位置 | 要求与用途 |
|---|---|---|
| DB | Worker D1 binding | 必需，现有project-tracker-db；不要初始化覆盖现有数据 |
| CF_D1_DATABASE_ID | 构建环境 | 完整build配置绑定时使用；由configure.mjs校验UUID并写wrangler.json |
| TRACKER_USER | Worker Secret | 必需，单使用者账号；资料密文owner也使用该值，改名需要资料迁移评估 |
| TRACKER_PASSWORD | Worker Secret | 必需，登录密码；修改会使既有签名会话失效 |
| VOCABULARY_SYNC_SECRET | Worker Secret + Apps Script属性 | 可选，词库签名推送；两边匹配，按VOCABULARY-SYNC.md配置 |
| PROJECT_CORE_SYNC_SECRET | Worker Secret + Apps Script属性 | 可选，至少32字符；启用后拒绝手工覆盖项目核心资料 |
| TMDB_API_TOKEN | Worker Secret | 影视资料推荐配置；兼容TMDB_API_KEY/TMDB_API，细节见MEDIA-SOURCES.md |
| IGDB_CLIENT_ID、IGDB_CLIENT_SECRET | Worker Secret | 游戏资料配置；兼容IGDB_ID/IGDB_SECRET |
| MAL_CLIENT_ID | Worker Secret | 动漫资料可选配置；兼容MAL_API |

运行时密钥与构建变量分开；`.dev.vars.example`只有空值示例，`.dev.vars`被忽略。本地合成验证使用独立假账号、临时状态，不加载真实.dev.vars。

生产分支/根目录/构建触发路径在Cloudflare控制台配置；本地配置不能证明控制台设置正确。实际部署版本、域名、WAF、备份保留期、构建Node版本与Apps Script授权状态仍需实际核实。
