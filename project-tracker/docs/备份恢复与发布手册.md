# 备份恢复与发布手册

更新于2026-10-22：经用户授权完成官方 Wrangler 登录、生产 D1 只读导出及独立 D1 恢复比对。未执行生产恢复、迁移或本批部署。下文原演练步骤保留为后续应用级验收清单。

## 完整备份范围

D1所有业务表及索引/触发器：以 sqlite_master 实际结构为准，不能只按固定表名备份。当前生产快照包含 tracker_state、tracker_history、calendar_images、account_vault、project_core_information、vocabulary_sheet_sync、login_attempts，以及 tracker_backup 触发器。wardrobe_images 在当前生产快照不存在；以后创建后也须纳入。Cloudflare内部 _cf_KV 不属于业务导出。必须连同图片BLOB和vault密文一起备份，普通workspace JSON导出、Git仓库和代码ZIP都不是全量数据库备份。另保存对应Git提交、锁文件、Worker配置、绑定及定时配置清单。真实Secret仅放受控密钥库，不写仓库/日志/备份说明。

独立资料密码无法从数据库恢复，需使用者自行保管。源Google表和Apps Script项目/触发器不属于D1快照，需要单独确认恢复方式。备份文件属于敏感资料，放仓库外受控存储，加密、限制访问并制定保留期。

## 恢复与应用级验收步骤（执行情况见下）

1. 确认目标数据库身份、恢复时间点和备份范围；从Cloudflare当前支持的D1导出/恢复能力取得受控快照，核对是否覆盖BLOB、索引和触发器，不能只看到导出成功就判定完整。
2. 创建独立测试数据库及Worker，绑定假账号，不复用生产域名、源表推送地址或生产同步密钥。暂停测试归档和外部推送，防止演练影响源数据。
3. 将快照恢复到隔离数据库，逐表比对数量、核心payload校验和、图片字节、vault信封、版本号；只报告摘要，不输出业务内容。
4. 验证登录、两个空间读取、项目及待办保存/冲突、图片加载、原密码解密、派生日历与提醒；验证失败保存不破坏原数据。
5. 记录备份时刻、耗时、丢失窗口、数据库身份、校验结果和恢复人；确认恢复目标与保留期。RPO/RTO目前未承诺。
6. 验收通过后再制定生产事故恢复方案；生产恢复须单独确认具体目标和覆盖后果。

本地 scripts/rehearse-recovery.py 只证明SQLite合成快照的SQL导出/恢复、BLOB与跨空间记录保留，不证明Cloudflare D1导出/Time Travel或真实账号密码恢复已通过。

## 本地构建与发布

- 干净环境：npm ci；首次/依赖变化后执行npm run build。该命令重建两个UI、页面并由configure.mjs写入数据库绑定ID，需CF_D1_DATABASE_ID（或已配置的有效ID）。
- 不准备部署时，可npm run build:ui、npm run build:pages、npm run verify，不需要生产数据库ID。
- npm run verify检查产物一致性并执行Node测试；不会部署。
- npm run deploy的predeploy执行完整build，随后verify再部署。直接npx wrangler deploy会绕过npm门禁；云端部署设置应采用npm run deploy或独立执行build和verify后部署。
- 提交前检查git diff，只包含本批文件；核对新生成资源、许可证、锁文件及数据库配置；不得提交本地假数据库ID和业务快照。
- 发布前提供具体改动、验证结果、未验证项和回滚点，取得本批发布确认。当前未提交、未推送、未部署。

记录部署ID与Git提交；验证登录、/work、/personal、/projects、已有记录、保存/冲突、图片、提醒及同步状态，确认18点归档配置。回滚应用使用已知可用代码版本；代码回滚不会回退已写数据库。遇到格式变更必须核对兼容性，不把应用回滚当数据恢复。数据库恢复另按确认的恢复方案执行。

## 本地D1回归

`npm ci` 后执行 `npm run test:d1`。脚本使用固定版本Miniflare、临时目录和合成账号/记录，不读取.dev.vars、不绑定远端、不访问外部资料服务。覆盖登录、工作/私人/项目交替保存、幂等新增、字段冲突、图片BLOB、加密信封读写与版本冲突、项目删除及Basic限流。

当前本地模拟器使用2026-07-30兼容日期；生产配置为2026-10-09。本地回归不证明生产兼容日期已通过，发布前仍需匹配环境验证。开发预览可执行 `node scripts/verify-local-d1.mjs --serve`；结束时Ctrl-C清理临时数据库。
