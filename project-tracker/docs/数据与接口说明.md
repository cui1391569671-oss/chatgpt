## 保存契约

operations包含collection、id、action；create传record；update传各字段before/after（含exists）；delete传before。ID稳定，同一新增重试幂等。不同记录/字段可合并；同字段变化或删除前记录变化返回409；核心状态行竞争最多重试5次，失败503。保存失败保留页面输入，不显示已保存。旧完整接口暂不移除。

## 认证与请求边界

浏览器优先通过登录取得Secure/HttpOnly/SameSite Cookie。旧浏览器通过有效Basic验证后也自动取得会话Cookie；后续请求优先验证Cookie，即使浏览器仍发送缓存的Authorization，也不重复消耗密码认证额度。表单登录与每次Basic请求共用每IP每固定十分钟桶10次额度；Basic成功请求也计数，长期轮询应使用会话Cookie。超限429，数据库限流不可用503；Cookie业务请求不消耗认证额度。Cloudflare层是否有额外WAF限制尚未核实。

写接口仍校验Origin与内容类型。主状态/空间JSON上限1500000字节，项目资料1000000字节、登录4096字节、衣橱JPEG180000字节、日程JPEG240000字节；限额按流读取。密文接口与签名推送已有独立流式限制。

本说明不是完整OpenAPI契约，也不是生产已验证声明。

## 第二批本地新增接口（待上线）

- GET /api/maintenance/audit：登录后返回状态字节数、工作/私人集合数量、项目校验规则及路径；不返回业务正文，不写库。
- GET /api/maintenance/images：登录后只读枚举现有图片表与引用；返回候选/缺失引用供核查。无清理实现，automaticDeletion=false；其他方法405。
- POST /api/security/csp-report：登录保护；允许CSP/Reporting API JSON，流式最多16384字节、最多处理20条。仅记录指令、被阻止来源origin/协议和报告模式；丢弃文档URL、路径、查询、代码样本。无效400、类型415、超大413、成功204。
- 主应用HTML增加Content-Security-Policy-Report-Only。仅观察，不拦截资源；登录已有强制策略保留。观察到报告后逐项核对真实依赖，再决定是否收紧。
- 项目patch与兼容整包保存新增 project-validation.mjs：真实YYYY-MM-DD、字段长度、完成状态、回收站、ID。违规旧字段原值可保留，改成另一违规值或新增违规值拒绝400；仍保留版本/字段冲突409及工作/私人隔离。
