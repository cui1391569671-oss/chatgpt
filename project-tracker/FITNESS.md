# Fitness page references

- Free Exercise DB: https://github.com/yuhonas/free-exercise-db — Unlicense/public-domain dataset; no upstream application code copied. Chinese summaries independently authored from the verified JSON entries: Bodyweight_Squat, Pushups, Butt_Lift_Bridge, Plank. Source checked 2026-10-18. No remote media embedded.
- wger: https://github.com/wger-project/wger — AGPL-3.0-or-later application; reference for workout organisation and logging only. No code, media, or exercise data copied from wger.

Scope: home bodyweight training; examples are adjustable, not personalized training prescriptions. The source repository is an exercise reference, not proof of suitability for an individual.

Data: private `fitnessSessions` records stored alongside existing workspace collections; no migration required. Local preview uses synthetic data and does not modify production. Production publishing requires explicit user approval.

## Original GIF demonstrations
Four schematic GIFs and static PNG posters are generated by `generate-fitness-media.py` using independently authored vector poses, not downloaded exercise-library media. `fitness-media.mjs` embeds them for authenticated same-origin delivery. The illustrations are simplified movement cues alongside the textual steps, not anatomical assessments. Plank retains a stationary body position and uses a subtle breathing cue. No third-party media license or external media request is required.

## Editable training profile
A private `fitnessProfiles` collection stores one `main` profile: optional adult age, height and weight; goal, experience, available days/minutes, optional mat, floor availability, and explicit excluded exercise IDs. It is separate from the encrypted identity-document vault. There is no external AI or fitness API transfer.

Saving regenerates only the next plan, using experience-based example sets, a simple time budget including transitions/rest, available training days and hard action/floor exclusions. Body size and chronological age do not automatically scale load; a mat does not change difficulty. Goals favour general fitness, basic strength or a short habit-building session. This is a transparent starter arrangement from the current four-action library, not an optimized or clinical plan. All-excluded conditions produce an empty plan, never a fallback that overrides exclusions.

General background references: NHS strength exercises (https://www.nhs.uk/live-well/exercise/strength-exercises/) and CDC adult activity guidance (https://www.cdc.gov/physical-activity-basics/adding-adults/). These support gradual introduction and a balanced weekly routine; the application’s exact numerical examples are product defaults, not validated personalized prescriptions.
